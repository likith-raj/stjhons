REAL-TIME VALIDATION (10+ CHECKS)
================================================================================

All these validations work LIVE and show red error boxes if violated:

✅ Auction Name must be filled
✅ Teams count must be > 0
✅ Players/Team must be > 0
✅ Budget Total must be > 0
✅ Budget Base must be > 0
✅ Base Price × Slots ≤ Total Purse
✅ Teams count must match Teams section
✅ All team names must be filled
✅ Bidding rules must be set (or all cleared)
✅ Enough players loaded (or extra allowed)

If ANY validation fails → RED ERROR BOX appears → START button disabled

================================================================================
KEYBOARD SHORTCUTS (DURING LIVE AUCTION)
================================================================================

1-9    = Place bid from Team 1-9
Enter  = SELL (confirm bid, next player)
U      = UNSOLD (skip player, re-auction pool)
Z      = UNDO (remove last bid)

Perfect for fast-paced auctions!
